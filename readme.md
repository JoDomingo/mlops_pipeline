# Proyecto Integrador Módulo 5 - MLOps Pipeline

Proyecto Integrador que corresponde al Módulo 5 **Fundamentos de Nube y Ciencia de Datos de Producción** de la carrera de Data Science de Henry.

## Objetivo

Desarrollar un proyecto de Machine Learning orientado a la predicción del comportamiento crediticio de nuevos usuarios, aplicando prácticas de versionamiento, reproducibilidad y MLOps.

El proyecto seguirá una arquitectura de carpetas predefinida y un flujo de trabajo basado en ramas para representar las distintas etapas de desarrollo, certificación y producción.

## Estructura del proyecto

```text
mlops_pipeline/
│
├── src/
│   ├── Cargar_datos.ipynb

│   ├── ft_engineering.py
│   ├── model_training_evaluation.py
│   ├── model_deploy.py
│   └── model_monitoring.py
│
├── Base_de_datos.csv
├── requirements.txt
├── .gitignore
└── readme.md
```

## Versionamiento

El proyecto utiliza las siguientes ramas principales:

- `developer`: desarrollo y experimentación.
- `certification`: validación de los cambios.
- `main`: versiones estables del proyecto.
